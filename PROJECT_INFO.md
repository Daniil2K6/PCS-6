# 📊 Информация о проекте

## Название

## 📋 Выполненные требования

### Обязательные требования

- ✅ **BlazorClient (WebAssembly)** - Полнофункциональный клиент
  - Blazor WebAssembly Standalone приложение
  - Интерактивный интерфейс
  - Асинхронная загрузка данных

- ✅ **BlazorServer (ASP.NET Core Host)** - REST API сервер
  - ASP.NET Core Web API приложение
  - Controllers для обработки запросов
  - CORS для безопасности

### API Endpoints

- ✅ **GET /api/products** - Получить список всех товаров
  - Возвращает 200 OK с JSON массивом
  - Отсортировано по дате создания (новые первые)

- ✅ **POST /api/products** - Добавить новый товар
  - Принимает JSON с данными товара
  - Валидирует входные данные
  - Возвращает 201 Created с созданным товаром

- ✅ **PUT /api/products/{id}** - Изменить товар
  - Принимает ID и обновленные данные
  - Проверяет существование товара
  - Возвращает 200 OK с обновленным товаром

- ✅ **DELETE /api/products/{id}** - Удалить товар
  - Принимает ID товара
  - Проверяет существование товара
  - Возвращает 200 OK с подтверждением

### Пользовательский интерфейс

- ✅ **Страница отображения товаров**
  - Таблица со всеми товарами
  - Отображает: ID, Название, Описание, Цену, Количество
  - Динамическая загрузка данных с сервера

- ✅ **Форма добавления нового товара**
  - Модальное окно
  - Поля: Название, Описание, Цена, Количество
  - Валидация перед отправкой
  - Успешное добавление обновляет таблицу

- ✅ **Форма изменения товара**
  - Загружает текущие данные товара
  - Позволяет изменить все поля
  - Отправляет PUT запрос
  - Обновляет таблицу после сохранения

- ✅ **Возможность удаления товара с запросом подтверждения**
  - Нажатие кнопки "Удалить"
  - Модальное окно подтверждения
  - Предотвращает случайное удаление
  - Удаляет из БД и обновляет UI

### Дополнительные требования

- ✅ **Хранение данных в БД с Entity Framework Core**
  - SQL Server LocalDB как хранилище
  - Entity Framework Core для работы с БД
  - Автоматическое создание БД
  - Индексы для оптимизации

- ✅ **Реализация тем оформления (светлая/темная)**
  - Переключатель в верхней панели
  - Светлая тема по умолчанию
  - Темная тема с приятным цветовым схемом
  - Применяется ко всем элементам интерфейса

## 🏗️ Архитектурные паттерны

### Используемые паттерны

1. **Three-Tier Architecture**
   - Presentation (Blazor Client)
   - Business Logic (ASP.NET Core API)
   - Data Access (Entity Framework Core)

2. **Dependency Injection**
   - Services регистрируются в Program.cs
   - Внедряются через конструкторы компонентов

3. **Observer Pattern**
   - ThemeService уведомляет компоненты об изменениях
   - Event-driven архитектура

4. **Repository Pattern**
   - Entity Framework как абстракция БД
   - LINQ для запросов

5. **MVC/API Controller Pattern**
   - ProductsController обрабатывает API запросы
   - Разделение concerns'ов

## 🔒 Безопасность

### Реализованные меры

1. **HTTPS только**
   - Все запросы через защищенные каналы
   - SSL сертификаты для dev окружения

2. **CORS конфигурация**
   - Разрешены только известные источники
   - Контролирует доступ к API

3. **Валидация данных**
   - На клиенте: быстрая обратная связь
   - На сервере: основная защита
   - Проверка всех входных данных

4. **Entity Framework защита**
   - Параметризованные запросы
   - Защита от SQL injection
   - Контролируемый доступ к данным

5. **Обработка ошибок**
   - Graceful error handling
   - Логирование ошибок
   - Информативные сообщения

## ⚡ Производительность

### Оптимизации

1. **Индексы БД**
   - IX_Products_Name - быстрый поиск по названию
   - IX_Products_CreatedAt - быстрая сортировка по дате

2. **Асинхронные операции везде**
   - Async/await в API контроллерах
   - Non-blocking IO операции
   - Может обрабатывать много пользователей

3. **Минимизация трафика**
   - JSON сериализация
   - Только необходимые поля
   - Кэширование на клиенте (возможно добавить)
